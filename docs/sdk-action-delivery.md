# SDK ACTION 수신 확인과 재접속 복구

QA ACTION은 DB 로그를 commit한 뒤 SDK로 보낸다. WebSocket 전송 큐에 들어간 상태와 SDK가 수신한 상태는 다르다.

SDK는 연결 URL에 `actionDelivery=1&processId=<UUID>`를 보내 이 계약을 지원한다고 알린다. `processId`는 같은 서버와 게임 instance로 재접속하는 동안 유지하고, 연결 대상이나 SDK 프로세스가 바뀌면 새로 만든다.

## 요청과 응답

QA 요청의 기존 outer `id`를 그대로 사용한다. 예시는 테스트의 요청 45228이다.

```json
{
  "type": "ACTION",
  "id": 45228,
  "actions": [{"id": 1, "jsonrpc": "2.0", "method": "reset_game", "params": [{"clearPlayerPrefs": true}]}],
  "delivery": {"processId": "11111111-1111-1111-1111-111111111111", "expiresAtUnixMs": 1800000025000}
}
```

SDK는 실행 대기 목록과 journal에 등록한 뒤 수신 ACK를 보낸다.

```json
{"type":"ACTION_ACCEPTED","requestId":45228,"processId":"11111111-1111-1111-1111-111111111111"}
```

완료 시 기존 `ACTION_RESULT`에 같은 `requestId`와 `processId`를 실어 보낸다. ACK는 실행 성공을 뜻하지 않는다.

## 재전송과 중복 실행 방지

- 서버는 같은 JSON과 outer `id`로 재전송한다. ACK 전에는 2초, ACK 뒤에는 결과 복구를 위해 5초 간격으로 보낸다. 최초 전송을 포함해 최대 6회, 서버가 요청 처리를 시작한 뒤 25초 이내다. DB commit을 기다리다 만료됐다면 최초 전송도 하지 않는다.
- 같은 SDK 프로세스의 새 세션이 등록되면 미완료 요청을 복구한다. 종료된 QA, 만료된 요청, 다른 프로세스나 구버전 SDK에는 재전송하지 않는다.
- 일반 연결 종료도 복구 대상 pending이 있으면 5초간 같은 프로세스의 재접속을 기다린다. 돌아오지 않으면 원래 QA try만 실패 처리한다. 지원하지 않는 SDK는 기존 종료 처리를 유지한다.
- SDK가 이미 실행 중인 ID를 받으면 ACK만 다시 보낸다. 완료된 ID는 보관한 결과를 다시 보내며 게임 효과를 재실행하지 않는다.
- 같은 ID에 다른 요청 내용이 오면 거절한다. ACK나 결과는 현재 세션과 대상 프로세스가 일치해야 인정한다.
- 연결 종료나 실행 예외로 중단된 요청은 실행 여부 미확인 실패로 보관한다. 일부 효과가 발생했을 수 있으므로 같은 ID를 다시 실행하지 않는다.
- 서버가 결과를 받은 뒤 agent 중계에 실패하면 SDK의 결과 재응답으로 중계를 재시도한다. 로그와 agent 봉투의 식별자는 같은 값을 유지한다.

## 적용 범위와 제한

자동 재전송은 QA ACTION에만 적용한다. 스캔·화면 캡처 등 별도 요청 ID 공간에는 이 변경으로 재전송을 추가하지 않는다. 구버전 SDK에는 `delivery` 필드를 보내지 않고 기존 단발 전송을 유지한다.

서버 pending과 SDK journal은 메모리에 있다. 서버나 게임 프로세스를 재시작한 뒤의 exactly-once를 보장하지 않는다. SDK journal은 최대 1024개이며 실행 중 항목을 밀어내지 않는다. 만료된 미등록 요청은 실행하지 않는다.

만료 검사는 서버와 게임의 UTC clock이 동기화되어 있어야 한다. SDK는 실행을 시작할 때도 만료를 확인한다. 25초는 실행 시간 제한이 아니며 이미 시작한 긴 작업을 강제로 끝내지 않는다. 이 기간 이후 결과 재전송 복구는 중단되고 agent의 기존 timeout 정책이 적용된다.

서버와 SDK는 capability 협상으로 독립 배포할 수 있다. 신규 SDK로 빌드한 게임이 연결되어야 자동 복구가 활성화된다. 각 commit을 revert하면 이전 동작으로 돌아간다.
